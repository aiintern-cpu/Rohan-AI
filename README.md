# 🤖 Rohan — AI Companion ChatBot

A personalized **AI Companion** built with **FastAPI** and powered by **Google Gemini**, designed to engage in meaningful, emotional, and fun conversations.  
Rohan understands user intent, adapts to personal preferences, and provides empathetic, context-aware responses.

---

## 🌟 Features

- 🧩 **User Authentication** — Signup and Signin APIs  
- 💬 **Smart Conversation Handling** — Classifies messages as:
  - `Suggestive` → gives advice or tips  
  - `Discussive` → has meaningful emotional conversation  
  - `Humorous` → responds with jokes or playful tone  
  - `Help` → provides compassionate mental-health support  
- 🧠 **Profile Enrichment** — Learns user favorites, events, and people from chat history  
- 📂 **JSON Database** — Lightweight local data storage  
- 🌈 **Context-Aware AI Replies** — Uses recent chat history and profiles for natural responses  
- ❤️ **Emotional Safety** — Includes mental health helplines for distress cases  

---

---

## 🚀 Project Workflow

1. **Signup** → User creates an account  
2. **Signin** → User logs in  
3. **Chat** → Sends message → Backend classifies → Generates AI response  
4. **Save Conversation** → Stored in user’s JSON file  
5. **Profile Enrichment** → Every 15 user messages, extracts:
   - Favorites (likes/interests)
   - Events (life updates)
   - People (relationships)  
6. **Return Reply** → AI’s contextual response sent back to frontend

## 🧑‍💻 Setup Instructions

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/aiintern-cpu/Rohan-AI
cd Rohan-AI
```

### 2️⃣ Create and Activate Virtual Environment
```bash
python -m venv venv
source venv/bin/activate    # For Linux/Mac
venv\Scripts\activate       # For Windows
```

### 3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```
*(If requirements.txt not present, manually install)*
```bash
pip install fastapi uvicorn python-dotenv google-genai
```

### 4️⃣ Create `.env` File
```
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 5️⃣ Run the Server
```bash
uvicorn app:app --reload
```

### 6️⃣ Access API Docs
Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 🧠 How It Works

1. **Classify Message Intent** → Gemini analyzes user input into 4 categories.  
2. **Generate AI Response** → Based on user profile, history, and intent.  
3. **Save Chat History** → User’s conversation appended to JSON database.  
4. **Enrich User Profile** → Gemini extracts key personal data from chats to make future responses more tailored.
